# Zestaw 2
1. Sprawdzanie, czy sekwencja liczb naturalnych jest ciągiem graficznym + konstrukcja grafu prostego o zadanych stopniach.
2. Randomizacja grafów prostych o zadanych stopniach: wielokrotnie zamieniać losowo wybraną parę krawędzi ab i cd na parę ad i bc.
3. Największa spójna składowa grafu.
4. Używając powyższych programów: losowy graf eulerowski + cykl Eulera.
5. Generowanie losowych grafów k-regularnych.
6. Sprawdzanie (dla małych grafów), czy graf jest hamiltonowski.

**Uwagi:** wizualizacja dowolna (nie musi być na okręgu). Zad. 2 i 3 można połączyć z zad. 1.
Punktacja: nie podano.
