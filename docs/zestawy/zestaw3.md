# Zestaw 3
1. Korzystając z programów z poprzednich zestawów wygenerować spójny graf losowy; każdej krawędzi przypisać losową wagę naturalną z zakresu 1–10.
2. Algorytm Dijkstry: najkrótsze ścieżki od zadanego wierzchołka do pozostałych + ich długości.
3. Macierz odległości między wszystkimi parami wierzchołków.
4. Centrum (min. suma odległości) i centrum minimax (min. odległość do najdalszego).
5. Minimalne drzewo rozpinające (Prim lub Kruskal).

**Uwagi:** cały program w jednym uruchomieniu pracuje na jednym losowym grafie z wagami. Punktacja: nie podano.
