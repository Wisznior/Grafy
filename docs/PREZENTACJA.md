# Checklista przed prezentacją (15 min)
- [ ] Każda osoba umie opisać każdy moduł (nie tylko swój).
- [ ] Demo działa na przykładach z `data/examples/` – jedna komenda na zadanie.
- [ ] `docs/ZRODLA.md` ma link/tytuł+autora dla każdego algorytmu zestawu.
- [ ] Algorytmy z treści zestawu są własne (biblioteki tylko do wizualizacji/testów).
- [ ] Rozkład czasu: ~8 min demo, ~7 min pytania.
- [ ] Repo na `main` jest w stanie z prezentacji (tag `zestaw-N`).
